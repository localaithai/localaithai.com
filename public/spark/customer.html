Connect your toolตั้งค่าเครื่องมือของคุณ

Codex CLI — ~/.codex/config.toml

model = "claude-spark"
model_provider = "spark"

[model_providers.spark]
name = "LocalAI Thailand Spark"
base_url = "https://spark.dgxthai.com/v1"
env_key = "SPARK_API_KEY"
wire_api = "responses"
export SPARK_API_KEY=<your key>
codex

The provider id has to be spark: openai, ollama and lmstudio are reserved names in Codex.

Claude Code

export ANTHROPIC_BASE_URL=https://spark.dgxthai.com
export ANTHROPIC_AUTH_TOKEN=<your key>
export ANTHROPIC_DEFAULT_MODEL=claude-spark
export ANTHROPIC_DEFAULT_FAST_MODEL=claude-spark-fast
claude

No /v1 on ANTHROPIC_BASE_URL — Claude Code appends /v1/messages itself. claude-spark is tier 1 and claude-spark-fast is tier 3; the names carry "claude" because Claude Code filters model ids on it.

Hermes Agent

export OPENAI_BASE_URL=https://spark.dgxthai.com/v1
export OPENAI_API_KEY=<your key>
hermes chat --provider openai-api --model claude-spark

curl

curl -s https://spark.dgxthai.com/v1/chat/completions \
  -H "Authorization: Bearer <your key>" -H 'Content-Type: application/json' \
  -d '{"model":"metalspork/qwen3.8-flash-next-ud:UD-IQ4_XS","messages":[{"role":"user","content":"hi"}]}'

OpenAI Python SDK

from openai import OpenAI

c = OpenAI(base_url="https://spark.dgxthai.com/v1", api_key="<your key>")
print(c.chat.completions.create(
    model="metalspork/qwen3.8-flash-next-ud:UD-IQ4_XS",
    messages=[{"role": "user", "content": "hi"}]).choices[0].message.content)

Anything else that takes an OpenAI base URL works the same way. GET /v1/models with your key lists what you can call.

What to expectสิ่งที่จะเจอระหว่างใช้งาน

  • Speed by tier. Tier 3 answers as fast as you can read. Tier 2 is comfortable for chat. Tier 1 is the slowest and the best — it is a 125B model on one box, not a datacentre.
  • One big model at a time. Either tier 1 is in memory, or tiers 2 and 3 are. Switching between those two groups costs about 20 seconds on the first request afterwards. Later requests are normal speed.
  • First request after a quiet spell can be slow for the same reason. It is warming up, not broken.
  • 32K tokens of context per request across all three models.
  • One machine, our office. A handful of people at once is fine; it is not built for a whole department hammering it.
  • Very long single replies (past roughly 100 seconds of streaming) can be cut off by the network edge. Ask for the answer in parts if you hit that.

House rulesข้อตกลงการใช้งาน

  • The key is personal to you. Please do not share or publish it.
  • It expires 7 days after issue and simply stops working. Ask us if you need longer.
  • Keep it out of git. Use an environment variable, as every snippet above does.
  • This is a demo box. Do not point production traffic at it, and keep anything you genuinely cannot lose elsewhere.
  • Tell us if a key leaks — we revoke it and issue a new one in under a minute.
