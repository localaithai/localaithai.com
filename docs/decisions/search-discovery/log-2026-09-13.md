# Search discovery decision log, 2026-09-13

## Canonical origin is `https://www.localaithai.com`

- Status: Accepted
- Scope: Localaithai search and answer-engine metadata
- Supersedes: Scattered per-page origin literals

**Context.** The live `www.localaithai.com` host responds directly, while the apex host does not currently resolve. Existing page canonicals already use the www host, but the origin was duplicated in layout, sitemap, and page files.

**Decision.** `https://www.localaithai.com` is the canonical origin in `src/lib/site.ts`. Canonicals, social URLs, sitemap entries, robots sitemap declaration, JSON-LD identities, and llms.txt links derive from it.

**Why.** One reachable production host prevents internally conflicting indexation signals while the hosting configuration is corrected.

**Rejected.** Using the unresolved apex origin would publish canonicals and sitemap URLs that crawlers cannot fetch.

**Consequence.** Hosting must later configure the apex domain to redirect permanently to the www canonical host. When that works, a future decision can migrate the canonical origin with permanent redirects and updated Search Console properties.
