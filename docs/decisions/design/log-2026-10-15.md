# Design log, 2026-10-15

## A small sweep on the existing Mimir label

The user requested React Bits where applicable and design polish across the
portfolio. `ShinyText` is adapted as a CSS-only Astro component on the existing
Latin `Mimir Suites Cloud` substring in `CloudCTA`. Thai stays outside the effect.
The original text remains in server HTML with a solid cyan base; a decorative,
hidden-from-accessibility layer adds a light sweep without dimming the base.
Reduced motion removes that layer. No new island or canvas is added.

`InfiniteScroll` would obscure a finite set of offers and remove a clear end;
`FlowingMenu` would complicate the existing grouped navigation and its controls.
Neither improves the buying path, so neither is placed.

## Readability before hydration

Content entrances and the page wrapper render visible by default, including the
hero headline. The shared island motion configuration skips animations when the
visitor requests reduced motion and subscribes to preference changes. Existing
grid and frame-sequence scenes remain, including their reduced-motion alternatives.

Base and component defaults sit in Tailwind layers so utilities can override
them; the unlayered root token precedence stays intact. Gradient heading classes
use their corresponding solid accents. Muted text uses the existing secondary
ink, and transitions name the properties they change. Noninteractive cards no
longer lift on hover. Focus uses cyan outlines, controls keep 44px targets, Thai
labels keep normal spacing, and blog summaries, quotations and callouts use full
borders. Copy, headings, metadata, URLs, CTA attributes and image instances remain.
